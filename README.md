# Family Money Tracker

A private, installable family ledger for teaching kids how to divide and manage money.

## What it does

- Adds a separate ledger for each child
- Splits every job payment into five equal shares
- Tracks the Pocket, Short Term, and Long Term shares
- Records spending and manual adjustments by category
- Keeps a complete transaction history
- Exports and restores JSON backups
- Works offline as an installable PWA

Data stays in the browser on the current device. No account or server is required.

## GitHub Pages

The repository includes a GitHub Actions workflow that publishes the site whenever `main` is updated.
